# ABC467 C - Adjacent Sums (easy)

## 問題の要約
0/1からなる数列Aに対し、隣接和 A_i + A_{i+1} を mod 2 でB_iに一致させるための最小操作回数(1加算)を求める。M=2固定のeasy版。

## Difficulty
茶：752

## 結果
AC(CEを繰り返した後にAC。WAはない)
18 ms　5044 KiB	

## 方針
- A_1 + A_2 ≡ B_1 (mod 2) の関係から、A_1を固定すれば A_2, A_3, ... が連鎖的に一意に決まる
- M=2なので A_1 の候補は 0 か 1 の2通りのみ → 全探索してコスト最小を採用

## 詰まった点
解法の発想自体はすぐ出たが、「A_1を固定して連鎖的に決める」実装に落とし込む過程で文法ミスによるCEを何度も出した。ロジックではなく実装レベルでの詰まりだった。
